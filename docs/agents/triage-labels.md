# Etiquetas de triage

Los skills hablan de cinco roles canónicos. Esta tabla los mapea a las etiquetas de este repo. Son
aparte de las etiquetas de área (`proto`, `render`, `ui`, `mundo`, `servidor`, `docs`).

| Rol en mattpocock/skills | Etiqueta en el repo | Significado                                   |
| ------------------------ | ------------------- | --------------------------------------------- |
| `needs-triage`           | `needs-triage`      | Hay que evaluarlo                             |
| `needs-info`             | `needs-info`        | Esperando más información de quien lo abrió   |
| `ready-for-agent`        | `ready-for-agent`   | Especificado del todo, listo para un agente   |
| `ready-for-human`        | `ready-for-human`   | Lo tiene que implementar una persona          |
| `wontfix`                | `wontfix`           | No se va a hacer                              |

Cuando un skill nombra un rol, usar la etiqueta de la segunda columna. Editarla si el repo usa otros nombres.
